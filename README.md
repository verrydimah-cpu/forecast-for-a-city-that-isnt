A one-line weather forecast for Atlantis — sunny, bone-dry, and a 0% chance of flooding, because the mayor has learned absolutely nothing. The program writes the line to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
